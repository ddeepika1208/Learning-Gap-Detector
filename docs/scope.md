\# Scope



\## In scope

\- Topics: C programming and DSA with C (15 concepts)

\- Concept prerequisite graph

\- Mastery score (0 to 1) per student per concept

\- Smart question selection from 30 reviewed questions

\- Student test screen and mastery view

\- Teacher dashboard: class averages, weakest concepts, students needing help

\- Small pilot with 10-20 real students



\## Out of scope

\- Other languages (Python, Java) and other subjects

\- Running or auto-grading student code

\- Native mobile apps (the web app works on phones)

\- Integration with college systems (LMS, ERP)

\- Large-scale deployment and advanced security

\- Proof of long-term learning gains (the pilot only measures feedback)
